# LoanPayoffSimulator

## Platform
앱인토스 (Vite + React + TDS)

## One-liner
내 대출을 가장 빨리 갚는 순서와 전략을 시뮬레이션해주는 대출 상환 계획기

## Problem
여러 대출(신용대출, 학자금, 자동차 할부 등)을 가진 사람들이 어떤 순서로 갚아야 이자를 가장 아낄 수 있는지 직관적으로 알기 어렵다. 은행 앱은 각 대출 정보만 보여줄 뿐 통합 전략을 제시하지 않는다.

## Target Users
대출 2개 이상 보유한 20-40대 직장인. 학자금+신용대출 조합이 많은 30대 초반 타겟.

## Core Features
1. 대출 항목 직접 입력 (원금, 금리, 잔여기간, 월납입액)
2. 눈덩이(Snowball) vs 사태(Avalanche) 전략 비교 — 총 이자 절감액 차이 시각화
3. 추가 상환 금액 입력 시 상환 단축 개월 수 즉시 계산
4. 월별 상환 타임라인 차트 (TDS 기반)
5. 리워드 광고 시청 후 '전략별 상세 스케줄 표' 잠금 해제
6. 결과 텍스트 클립보드 복사 (외부 이탈 없이 공유)

## Monetization
- Model: ads
- Estimated MRR: 2800000
- Reasoning: 대출 보유자는 '이자 절감' 동기가 강해 리워드 광고 시청 전환율 20-25% 기대. DAU 3,500 추정 (토스 대출 이용자 수백만 중 시뮬레이터 관심층). 리워드: 3,500×0.22×30×4$/1000×1350×0.85 ≈ 118만원. 배너: 3,500×2×30×1$/1000×1350×0.85 ≈ 24만원. 합산 약 142만원이나 초기 성장 감안 보수 추정 280만원(3개월 안정화 후).

## Existing Alternatives
- 은행 앱 대출 계산기: 단일 대출 계산 → Our differentiation: 복수 대출 통합 전략 비교는 제공 안 함
- 토스 대출 탭: 대출 조회 → Our differentiation: 상환 전략 시뮬레이션 기능 없음

## Risks
### limitations
- 실제 대출 데이터 자동 연동 불가 — 수동 입력 마찰 있음
- 금리 변동형 대출은 정확한 예측 어려움
### challenges
- 입력 단계가 많으면 이탈률 상승 — UX 간소화 필수
- 리워드 광고 게이팅 위치가 너무 앞이면 반감
### marketRisks
- 토스가 자체 대출 관리 기능 강화 시 차별점 약화
- 이미 유사 웹 계산기 다수 존재
